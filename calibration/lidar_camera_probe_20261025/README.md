# 2026-10-25 雷达与 ZED 2i 外参检查

## 当前使用的几何关系

`src/vehicle/scout_vehicle_description/urdf/vehicle.xacro` 把 `rslidar` 放在传感器支架原点上方 0.434 m，把 `zed2i_link` 放在支架前方 0.099994 m、上方 0.248125 m；二者安装姿态都写成零旋转。`launch/scout_dataset.launch.py` 把 `zed2i_link` 与官方 wrapper 的 `zed2i_camera_link` 以零变换连接，后者的 `zed_description` 给出左目光学坐标系。

按已录 bag 中的 TF，**相对雷达原点**，ZED 安装点为车体 x 轴前方约 10.0 cm、z 轴下方约 18.6 cm；左目光心为前方约 9.5 cm、左侧约 6.0 cm、下方约 17.1 cm。这里 x 向前、y 向左、z 向上。用户现场目测相机在雷达正下方且仅前推几厘米，因此**前后安装距离须用实车量尺核对**；外壳外缘、安装螺孔与左目光心不是同一个点。左目光学坐标系中的 `T_optical_lidar` 为：

```text
[ 0 -1  0  0.060000 ]
[ 0  0 -1 -0.170875 ]
[ 1  0  0 -0.094994 ]
[ 0  0  0  1.000000 ]
```

## 使用已有 bag 的检查

- 室内静态包：`scout_dataset_20261024_144323_883795`，取约第 3、8、13 秒的同步图像、深度图、点云。雷达与彩色图消息头相差约 3–4 ms。把点云按当前 TF 投影到图像，结构物位置未见明显的大角度错位；[室内叠加图](frame_03_overlay.png)。与 ZED 深度图逐像素比较的中位绝对差为约 0.06、0.07、0.08 m；限制在局部平滑深度区域后约 0.05、0.06、0.07 m。这是**两种传感器的深度差**，并非外参真值误差。
- 室外包：`scout_dataset_20261024_161935_690795`，取约第 5、30、60、75 秒；雷达与图像时间戳相差约 16–21 ms。[室外叠加图](outdoor/frame_05_overlay.png) 显示地面、建筑等整体方向相符，但深度图与雷达的中位差约 0.28–0.38 m，且随距离明显增加。举例：第 30 秒样本，雷达 2–4 m 区间的深度差中位约 -0.24 m，6–10 m 区间约 -0.76 m。运动、遮挡和 ZED 双目深度偏差都会影响这项比较，因此不能把它直接当作雷达到相机的平移误差。
- 在室内三帧上做 ±3°、±8 cm 范围的深度对齐试探，所得修正仅约 0.1°、1 cm，但它让室外样本的比较值略变差。**没有跨场景稳定改进；未修改当前 URDF。**

这些叠加图是粗检，可排除明显的坐标轴方向错误或大幅错位；现有 bag 没有已知尺寸、在雷达和相机中都清晰可见的标定板，不能从当前结果证明厘米级外参精度，也不能可靠求一组新的六自由度外参。

## 要做正式标定

准备一块约 0.8–1.0 m 的平整硬质板，在板上贴棋盘格或 AprilTag 标记；板面须能在雷达点云中形成清晰平面。让车辆和板都静止，分别在约 2–5 m 距离、画面左/中/右、不同俯仰与偏航角度拍至少 8–12 组，每组保持 3–5 秒。bag 同时录彩色图、`camera_info`、雷达点云和 `/tf_static`。相机端用已知板尺寸求板位姿，雷达端拟合板平面，多组联合求雷达到左目光学坐标系的刚体变换；再用未参与求解的姿态验证重投影。量尺记录雷达坐标原点、ZED 安装螺孔及双目中心之间的前后/上下距离，可用来核验求解是否符合实车。

`sample_*.npz` 保存本次抽样的点云、深度、内参和 TF；PNG 是对应图像及投影叠加，供复查。ZED 内部左相机到 IMU 的 SDK 外参与本检查中的雷达到相机外参是两个不同关系。
